Quickstart

Install in 3 Simple Steps

No complicated terminal setups. An automated plain batch script handles Python, Ollama, and local models for you.

01

Download & Extract

Download pepper.zip directly. Right-click the downloaded zip, choose Extract All..., and pick a simple folder such as C:\PepperVA or your Documents folder.

Important Don't run anything from inside the zip file. Always extract first.
02

Double-Click Setup PepperVA.bat

Run Setup PepperVA.bat. It installs Python 3.11 and Ollama if you don't have them, then sets up Pepper's packages, voice, hearing, and brain models automatically.

  • If Windows says "Windows protected your PC", click More info, then Run anyway. The setup is a plain readable script.
  • Takes 15 to 40 minutes depending on internet (approx 4 GB download). If it stops, just run it again: it picks up where it left off.
03

Start PepperVA & Talk

Start PepperVA from the icon on your Desktop (or Start Menu). She lives in the system tray (bottom-right). The first start takes about a minute, then she says hello.

Ready Say "Hey Pepper" and talk!

Troubleshooting & Diagnostics

If Something Goes Wrong

Right-click the tray icon and choose Run Doctor, or double-click PepperVA Doctor.bat. It checks your setup and tells you exactly what to fix.

🩺

PepperVA Doctor Built-In

Generates a clear report at logs\doctor.txt. Send it alongside logs\setup.log if you need help.

PepperVA Doctor.bat
🎤

She doesn't hear me

Go to Windows Settings > Privacy & security > Microphone: turn on access, including "Let desktop apps access your microphone". Make sure the right mic is set as default and its volume is 80–100.

⚠️

Setup stopped with a message

Read the error message, resolve it, and run setup again. It automatically picks up right where it left off. Full details are recorded in logs\setup.log.

📦

"winget isn't available"

Install "App Installer" from the Microsoft Store, or install Python 3.11 (tick "Add python.exe to PATH") and Ollama from ollama.com manually, then run setup again.

🧠

She says she can't reach her brain

Open the Ollama app from the Start Menu, or restart your PC. Right-click the tray icon and run the Doctor to verify the connection.

⚡

Replies are slow

Create data\settings.json containing {"ollama_model": "qwen2.5:1.5b"} for a smaller, lightning-fast brain. Restart PepperVA afterwards.

🛡️

Antivirus warning

PepperVA is 100% open source and made of plain, readable batch scripts. If your antivirus flags it, inspect the file it names and allow it.

System Requirements

What You Need

Runs on everyday Windows hardware without high-end workstation specs.

SUPPORTED

Minimum Setup

  • Operating System Windows 10 (1809+) or Windows 11, 64-bit
  • System Memory 4 GB RAM (Setup picks smaller brain)
  • Free Disk Space About 8 GB free (~4 GB downloads)
  • Audio Devices Microphone & speakers / headphones
  • Internet Setup & weather lookups only
RECOMMENDED

Optimal Experience

  • Operating System Windows 11 (Latest 64-bit build)
  • System Memory 8 GB RAM (Full brain model)
  • Storage SSD for fast model weights loading
  • Audio Devices Dedicated mic (volume set to 80-100)
  • Post Setup 100% Offline voice assistant
