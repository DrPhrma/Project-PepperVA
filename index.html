System Requirements

Designed to run on everyday hardware.

Minimum

  • Windows 11
  • 4 GB RAM
  • 256 GB storage (SSD or HDD)
  • Integrated graphics (Intel Iris Xe / Xe Max or equivalent)
  • Ollama installed & running

Recommended

  • Windows 11
  • 8 GB RAM (dual-channel preferred)
  • 256 GB+ storage
  • Dedicated GPU (GTX 1650 or better)
  • Ollama installed & running

Pepper requires Ollama to run the local language model. Download it from the official site before installing Pepper.
