# Project PepperVA

**Local AI Voice Assistant for Windows**

Pepper VA is a fully local, voice-first AI assistant built in Python. It runs on your machine using Ollama, supports a custom wake word, persistent memory, desktop control, and a natural personality.

## Website

This repository hosts the official project website (GitHub Pages).

## System Requirements

**Minimum**
- Windows 11
- 4 GB RAM
- 256 GB storage
- Integrated graphics (Iris Xe or equivalent)
- Ollama installed

**Recommended**
- 8 GB RAM (dual-channel)
- Dedicated GPU (GTX 1650+)
- Ollama installed
